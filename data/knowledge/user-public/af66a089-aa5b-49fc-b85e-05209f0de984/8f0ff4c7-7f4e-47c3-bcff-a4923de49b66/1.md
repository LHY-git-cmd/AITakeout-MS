# 个性化饮食知识库使用边界与来源说明

## 文档用途

本知识库用于解释一般健康饮食原则、已发布食养规则以及推荐结果，不用于诊断疾病、解释化验结果、调整药物或替代医生和临床营养师。

运行时优先级：

```text
用户明确过敏与医生限制
> Java 结构化菜品、营养和规则结果
> 已发布权威知识
> 信息不足时拒绝确定性结论
```

知识文档不能直接改变过敏原状态、营养数值、菜品库存、价格或推荐排序。上述事实均以业务数据库中的已审核版本为准。

## 风险分级

- 日常偏好、人数和预算：可以直接辅助推荐；
- 减脂、清淡、高蛋白：基于已审核营养数据提供相对选择；
- 明确食物过敏：只允许选择已证明不含目标过敏原且加工风险明确的菜品；
- 已确诊常见慢病：只能使用已发布规则，结果仅辅助点餐；
- 呼吸困难、意识障碍、严重过敏反应、胸痛等急性危险症状：不继续点餐推荐，应尽快寻求紧急医疗帮助；
- 慢性肾病、透析、多病共存、妊娠并发症、肿瘤治疗期、药物与食物相互作用：需要专业人员个体化评估。

## 内容更新

- 规则和知识至少每年复核一次；
- 权威指南发生更新时创建新版本，不覆盖历史版本；
- 菜品配方或供应商改变时重新审核食材、营养和过敏原；
- 无法确认来源的网络养生内容不得进入已发布知识库。
