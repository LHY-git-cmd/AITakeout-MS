# 项目可交付化实施报告

> 完成日期：2026-10-07  
> 候选版本：v1.0.0-rc1

## 1. 交付目标

将项目从“当前电脑可运行”完善为可从Git仓库、环境配置和模型目录在干净环境重复部署的候选发布版本。最终业务手工验收由项目负责人执行。

## 2. 已完成改造

### 配置和启动

- 完善 `.env.example` 必填配置、双前端端口、管理员引导和图片目录；
- 新增配置预检脚本，检查Docker、密钥占位符、账号关系、模型完整性和Compose语法；
- 新增一键部署脚本，自动构建、启动、等待健康并执行冒烟测试；
- 新增只读冒烟脚本，检查Java、Agent、Embedding、Qdrant和两个前端；
- 新增干净数据库启动测试脚本。

### 数据库

- 新增无用户、无订单、无默认密码的核心业务表基线；
- 恢复9份只存在于旧构建产物、未进入源码目录的Flyway迁移；
- 核心基线补齐初始Agent表，使后续迁移可连续执行；
- Flyway迁移账号与Java业务账号分离；
- 增加环境变量驱动的首个超级管理员创建，密码使用BCrypt；
- 修复管理端Agent Mapper仍访问迁移前 `agent_*` 表的问题，统一访问 `admin_agent_*`。

### 前端和网关

- 新增Web多阶段镜像，在干净Node环境分别构建Vue 2管理端和Vue 3用户端；
- 新增双站点Nginx配置：管理端80端口、用户端8081端口；
- 两个站点分别处理 `/api` 路由，支持SPA回退、SSE和WebSocket；
- Docker Compose纳入Web服务及健康检查。

### 图片存储

- 菜品和套餐上传由OSS切换到 `server-data:/app/data/uploads/products`；
- 数据库保存相对URL；
- 增加格式、大小、像素和路径穿越校验；
- 管理端上传组件显示后端错误，不再把失败响应当作图片URL；
- 备份和恢复演练纳入 `server-data` 图片卷。

### 质量和文档

- 新增GitHub Actions四模块质量门禁；
- 新增README、Changelog和手工验收清单；
- 更新备份脚本和恢复演练；
- 所有新增PowerShell脚本包含用途说明，并通过语法解析。

## 5. 已知限制

- BGE-M3模型不进入Git，需要单独准备；
- 首次构建需访问Docker Hub、Maven、npm和PyPI；
- 全新数据库不提供演示业务数据，避免携带隐私和过时状态；
- 健康营养和地域时令模拟数据只能用于开发演示；
- 第三方支付、短信和地图在开发环境使用模拟实现；
- 管理端旧技术栈的静态包体积较大，但不阻断当前交付。
