# 阶段一：账号、支付基础与测试底座 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付正式手机号账号、可见模拟账户、双向账本、异步模拟支付、支付结果查询、15 分钟超时和首条移动端自动化链路。

**Architecture:** 新账号会话、账户和支付表通过 Flyway 引入；认证、账本和支付分别由独立应用服务负责。模拟支付实现统一 `PaymentGateway`，支付成功事务同时完成扣款、双向流水、订单状态和时间轴，为微信 H5 保留接口边界。

**Tech Stack:** Spring Boot 3.5.16、MyBatis、Flyway、MySQL/H2、BCrypt、JUnit 5、Mockito、Vue 3、Pinia、Vitest、Vue Test Utils、Playwright。

**Spec:** `项目文档/用户端传统业务全链路优化设计说明.md`

## Global Constraints

- Access Token 15 分钟；Refresh Token 30 天并使用 `HttpOnly + Secure + SameSite=Lax` Cookie。
- 模拟金额使用整数分；初始 50000 分、每次领取 50000 分、上限 1000000 分。
- 支付有效期 15 分钟；同一订单最多一笔成功支付。
- 支付结果只能由服务端查询或网关结果确认。
- 本阶段保留旧 `/user/user/login/web` 和 `/user/order/payment`，但新前端只调用新接口。
