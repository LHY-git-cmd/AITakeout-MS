# 项目交付与手工验收清单

## 一、自动交付检查

执行：

```powershell
.\scripts\test-delivery-preflight.ps1
.\scripts\deploy-clean.ps1
```

通过标准：

- MySQL、Redis、Qdrant、Embedding、Agent、Java和Web均为 healthy；
- Flyway失败记录为0；
- `employee`、`dish`、`orders`、`user` 四张核心表存在；
- 管理端和用户端首页均返回HTTP 200；
- 首次超级管理员可以由环境变量安全创建；
- 仓库不依赖 `target/classes`、IDE环境变量或旧数据库。

## 二、由项目负责人执行的手工验证

### 管理端

- [ ] 使用 `.env` 中配置的首个管理员登录；
- [ ] 新建菜品分类；
- [ ] 新建菜品并上传图片；
- [ ] 刷新页面后图片仍显示；
- [ ] 新建套餐并关联菜品；
- [ ] 切换店铺营业状态；
- [ ] 创建普通管理员并验证权限差异；
- [ ] 查看订单、报表和工作台。

### 用户端

- [ ] 注册、登录、刷新页面和退出；
- [ ] 浏览菜单和搜索商品；
- [ ] 加入购物车并调整数量；
- [ ] 新增配送地址；
- [ ] 结算试算、提交订单和模拟支付；
- [ ] 查看订单详情和状态时间线；
- [ ] 取消订单、退款和售后；
- [ ] 查看通知中心。

### Agent与知识库

- [ ] 管理端上传知识文件并完成索引；
- [ ] 创建并发布公共知识版本；
- [ ] 绑定用户会话场景；
- [ ] 用户端询问规则问题并显示引用；
- [ ] Agent推荐菜品后能够加入购物车；
- [ ] 感冒推荐不会出现已排除商品；
- [ ] 高风险医疗问题不会进入商品推荐；
- [ ] Agent、Embedding或RAG不可用时出现明确降级提示。

### 持久化和恢复

- [ ] 执行 `docker compose restart` 后用户、订单和知识仍存在；
- [ ] 商品图片重启后仍可访问；
- [ ] 执行备份脚本；
- [ ] 执行备份校验；
- [ ] 在测试环境完成一次恢复演练。
