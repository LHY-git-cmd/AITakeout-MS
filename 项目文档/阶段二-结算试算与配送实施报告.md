# 阶段二：结算试算与配送实施报告

## 1. 交付结论

阶段二已完成结算试算、配送预检、分段配送费、预约配送、权威核价、幂等下单及移动端结算页切换。用户从选择地址到提交订单的金额、配送范围和送达时间均以服务端结果为准，客户端不再决定订单金额。

实现分支：`codex/user-order-phase2`

## 2. 技术选型声明

1. 地图能力通过 `DeliveryMapGateway` 隔离：开发与自动化测试显式使用 `mock`，非开发环境默认使用 `baidu`；选择百度但缺少 `BAIDU_MAP_AK` 时启动失败，不允许跳过校验。
2. 所有权威金额使用整数分计算并保存；试算 Token 用于检测用户确认内容是否变化，正式提交仍重新查询购物车、商品状态和价格。
3. 下单幂等使用 `order_submission(user_id, idempotency_key)` 唯一约束；幂等占位、订单、明细和购物车清理处于同一事务，重复请求返回原订单。

## 3. 数据库变更

迁移文件：`V20260920_02__add_checkout_delivery_fields.sql`。原计划版本 `V20260918_02` 已被阶段一占用，因此使用新的唯一版本避免 Flyway 冲突。

- `orders`：增加商品、打包、配送、优惠和实付分金额，配送距离、地图提供方、配送模式、预约时段、地址坐标快照、支付过期时间、计价规则版本和乐观锁版本。
- `address_book`：增加经纬度、地理编码状态、地图提供方、配送距离、可配送标识、失败原因、校验时间和规则版本。
- `order_submission`：增加用户级幂等键、请求哈希和订单引用，唯一键为 `(user_id, idempotency_key)`。
- 旧 `amount` 元字段本阶段保留兼容，迁移按 `ROUND(amount * 100)` 回填 `amount_cent`。

## 4. 配送和地址预检

默认规则：

| 驾车距离 | 配送费 | 结果 |
| --- | ---: | --- |
| 0—3000 米 | 500 分 | 可配送 |
| 3001—5000 米 | 800 分 | 可配送 |
| 超过 5000 米 | 0 分 | 拒绝下单 |

模拟地图契约：`测试路 1 号` 为 1500 米，`测试路 2 号` 为 4200 米，`测试路 3 号` 为 6500 米；`无效地址` 返回不可识别错误，`超时地址` 返回可重试错误。普通未匹配地址默认映射为 1500 米，兼容既有验收数据。

地址新增、修改和 `POST /user/addresses/{id}/validate` 都会执行配送预检。失败时保留用户输入，并写入 `INVALID` 或 `TEMPORARY_FAILURE`；所有按 ID 操作均使用当前用户归属校验。

## 5. 权威试算和预约配送

新增 `POST /user/order/preview`：

- 从数据库读取当前商品或套餐状态与价格，拒绝已下架商品。
- 按购物车当前数量计算商品金额，打包费按每件 100 分计算。
- 重新计算驾车距离和分段配送费。
- 返回 30 分钟粒度的 16 个可预约时段；近距离最早 30 分钟、远距离最早 45 分钟送达。
- 返回费用明细、配送距离、预计送达时间、商品快照和 5 分钟有效的 HMAC 签名 Token。

## 6. 幂等下单与失败恢复

`POST /user/order/submit` 接收 `Idempotency-Key` 和 `previewToken`。服务端先建立幂等占位，再重新核价并验证 Token；成功后写入订单及商品、联系人、地址、配送规则快照并清空购物车。

- 同一用户和幂等键的并发请求只创建一个订单。
- 相同幂等键携带不同请求内容时拒绝。
- 客户端未收到响应时可使用原幂等键重试，即使购物车已清空也会返回原订单。
- 试算过期、商品价格变化、商品下架、地址超范围和预约时段失效都会阻止提交并要求重新确认。

## 7. 移动端结算页

- 删除本地固定配送费和本地总额计算，全部展示服务端试算结果。
- 地址、配送模式或预约时段变化时取消旧试算请求，防止晚到响应覆盖新选择。
- 支持立即配送和预约配送，并展示配送距离、预计送达时间与服务端商品快照。
- 失败时保留地址、备注和餐具选择，显示可聚焦的错误摘要与“重新试算”按钮。
- 提交中禁用主按钮；成功时提供轻量触觉反馈；移动端摘要区尊重底部安全区。
- 交互按 `ui-ux-pro-max` 的错误恢复、触控目标、焦点管理和安全区规则完成检查。

## 8. 配置

开发环境默认：

```yaml
sky.delivery.map-provider: mock
```

联调或生产环境：

```text
DELIVERY_MAP_PROVIDER=baidu
BAIDU_MAP_AK=<百度地图服务端AK>
CHECKOUT_PREVIEW_SECRET=<至少32字节的随机密钥>
SHOP_ADDRESS=<门店完整地址>
```
